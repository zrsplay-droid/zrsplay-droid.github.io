처음 한 번: GitHub 토큰 연결

  1. GitHub 오른쪽 위 프로필 → Settings → 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. 이름 아무거나, Expiration은 원하는 기간(최대 1년)
  3. Repository access → Only select repositories → zrsplay-droid.github.io 선택
  4. Permissions → Repository permissions → Contents → Read and write
  5. Generate token → 나온 github_pat_… 를 복사해서 아래에 붙여넣기

토큰은 이 브라우저에만 저장되고 다른 곳으로 보내지지 않아. 다른 기기에서 편집하려면 그 기기에서 한 번 더 넣으면 돼.
